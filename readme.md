## Как сделать из монолитного тг бота модульного: 
1) создайте папку app в которой создайте handlers.py
2) перенеси в handlers.py все @dp из основного файла бота (у меня bot.py)
3) перенести все from aiogram кроме Bot и Dispatcher
4) добавить к 
""
from aiogram import F
""
в handlers.py
добавить нада Router
""
from aiogram import F, Router
"
5) после чего в коде под всеми импортами (в handlers.py) создать router = Router()
6)  чтобы потом работало нужно ДОБАВИТЬ в основном файле, в функцию **main()** 
""
dp.include_router(router)
""
у меня в моём примере это 64 строка (или 5 с конца если изменю файл и забуду переписать тут)
а так же добавить в импорты основного файла from app.handlers import router
7) 



## Клавиатуры
**Reply** - та что вылезает снизу под полем ввода. Кнопки которые просто отправляют команды в чат (содержимое отправляется в чат у которой)

Inline - кнопки которые целяются снизу сообщения и привязаны к конкретному сообщению бота. (ну те, которые еще прозрачные)
